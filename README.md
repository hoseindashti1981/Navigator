# راه‌نگار — دفتر مسیرهای شخصی

برنامهٔ فارسی و راست‌به‌چپ برای ضبط مسیر واقعی GPS در Safari، ذخیرهٔ خصوصی روی هاست PHP/MySQL و دنبال‌کردن دوبارهٔ همان خط روی نقشه.

**مرورگر باید هنگام ضبط فعال و صفحه روشن باشد.** این برنامه راهنمای پیچ‌به‌پیچ، محاسبهٔ مسیر خیابانی، نقشهٔ آفلاین یا ضبط تضمین‌شده در پس‌زمینه ندارد. هیچ PWA، سرویس‌ورکر یا نصب اجباری وجود ندارد. نشان و گوگل‌مپ برای کارکرد برنامه لازم نیستند.

## قابلیت‌ها

- حساب خصوصی تک‌کاربره، رمز هش‌شده، نشست امن، محافظت CSRF و محدودیت تلاش ورود.
- ضبط رانندگی و پیاده‌روی با موقعیت‌یابی واقعی مرورگر؛ مکث، ادامه، پایان و انصراف.
- ذخیرهٔ نمونه‌ها در IndexedDB، ارسال دسته‌ای هر ۱۵ ثانیه و بازیابی ضبط ناتمام از دستگاه یا سرور.
- شناسه و شمارهٔ ترتیب یکتا، تکرار امن ارسال، نهایی‌سازی پس از رسیدن همهٔ نقاط و جلوگیری از احیای مسیر حذف‌شده.
- نگهداری زمان، دقت، سرعت و ارتفاع موجود؛ حفظ نمونه‌های نامطمئن با برچسب، بدون افزودن به خط معتبر.
- نمایش مستقل بخش‌های قطع‌شده و محاسبهٔ فاصله فقط روی بخش‌های ثبت‌شده.
- کتابخانه، جست‌وجو، ترتیب تاریخ، ویرایش نام و یادداشت، حذف با تأیید.
- دنبال‌کردن موقعیت، نمایش پیشرفت و فاصلهٔ باقیماندهٔ ثبت‌شده، انتخاب بخش در حالت مبهم و هشدار انحراف با توجه به دقت GPS.
- نمایش خط برگشت با هشدار محدودیت‌های راه؛ خروجی JSON، GPX و GeoJSON؛ ورود JSON و GPX دارای زمان.

## نصب

[راهنمای نصب روی هاست](docs/DEPLOYMENT.fa.md) را دنبال کنید. PHP نسخهٔ ۸٫۲ یا جدیدتر با PDO MySQL، mbstring، json و session؛ MySQL ۸ یا MariaDB ۱۰٫۶ به بالا؛ HTTPS و حدود ۱۲۸ مگابایت حافظهٔ PHP برای مسیرهای معمول توصیه می‌شود. محیط واقعی آزمون: PHP ۸٫۴ و MariaDB ۱۱٫۴.

فقط پوشهٔ `public` باید ریشهٔ وب زیردامنه باشد. پوشهٔ `private` کنار آن و خارج از ریشهٔ وب قرار می‌گیرد. WordPress نیازی به تغییر ندارد.

```text
Navigator/
  public/             رابط فارسی، API و فایل‌های محلی نقشه و فونت
    assets/           منطق موقعیت، ذخیره، رابط و کتابخانه‌های آزاد
  private/            منطق PHP و نمونهٔ تنظیمات خصوصی
  database/schema.sql ساختار MySQL / MariaDB
  docs/               نصب، آزمون، حریم خصوصی و پشتیبان‌گیری
  tests/              آزمون هندسه، PHP، API و دادهٔ ساختگی آزمون
  scripts/package.ps1 ساخت ZIP برای بارگذاری در هاست
```

ساخت بسته در ویندوز:

```powershell
pwsh -NoProfile -File scripts/package.ps1
```

خروجی `release/navigator-hosting.zip` است و تنظیمات واقعی، رمزها، داده‌های آزمون و ابزارهای توسعه در آن قرار نمی‌گیرند. Node.js فقط برای آزمون توسعه است و روی هاست لازم نیست.

## آزمون

```text
node --test tests/geo.test.mjs
php tests/backend.php
php -l public/api.php
```

آزمون API به پایگاه خالی و موقت محلی نیاز دارد؛ دستورها و چک‌لیست آیفون در [راهنمای آزمون](docs/TESTING.fa.md) هستند. آزمون خودکار معادل آزمون واقعی آیفون نیست.

## محدودیت‌ها و مجوزها

دقت نقاط به GPS و محیط بستگی دارد. خط معکوس، مجوز حرکت در خلاف جهت راه را تأیید نمی‌کند. بخش‌های ثبت‌نشده با خط فرضی پر نمی‌شوند. نقشهٔ زمینه به سرویس بیرونی نیاز دارد و شرایط آن باید رعایت شود؛ جزئیات در [حریم خصوصی و منابع](docs/PRIVACY.fa.md).

Leaflet با مجوز BSD-2-Clause و وزیرمتن با مجوز SIL OFL به‌صورت محلی همراه پروژه‌اند؛ متن مجوزها در `public/assets/vendor` موجود است.
